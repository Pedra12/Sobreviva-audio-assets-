# Sobreviva às Suas Ideias 3D — Áudio

Repositório de arquivos de áudio usados no jogo **Sobreviva às Suas Ideias 3D**.

## Como enviar os arquivos

1. Toque em **Add file** e depois em **Upload files**.
2. Selecione os arquivos de áudio no celular. Você também pode enviar um arquivo ZIP sem descompactar.
3. Aguarde o upload terminar e toque em **Commit changes**.

## Organização sugerida

- `thunder/` — trovões e estrondos distantes.
- `lightning/` — estalos e descargas elétricas.
- `wind/` — vento contínuo e rajadas.
- `destruction/` — impactos e destruição de construções.
- `character/` — passos, saltos, aterrissagens e impactos do personagem.

## Observações

- Envie também o arquivo de licença ou os créditos do pacote, se houver.
- Não é necessário renomear nem converter os arquivos antes do envio.
- Este repositório é separado do código principal do jogo e serve apenas para reunir os efeitos sonoros.
